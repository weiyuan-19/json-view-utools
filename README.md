# JSON 编辑器（uTools 插件）

一个基于 CodeMirror 的本地 JSON 编辑插件，支持带注释的 JSONC，可从 uTools 命令、JSON 文本或 `.json` / `.jsonc` 文件打开。

## 功能

支持 `//` 行注释和 `/* … */` 块注释，并正确高亮注释。粘贴有效 JSON / JSONC 后自动按 4 个空格格式化，格式化保留注释；格式化和压缩均保留重复属性名、数字写法及字符串转义的原始文本。选中文字时显示缩进空格。对象和数组可通过行号旁箭头折叠，也可使用底部“折叠全部”“展开全部”递归处理所有层级，折叠处显示项目数。

编辑时会实时标记 JSON 语法错误和重复属性名警告：文本下方显示波浪线；右侧滚动条概览用细线标记当前光标行，光标贴着对象或数组的括号时再标出该结构的起止行，并显示错误、警告所在行。悬停可查看说明。右上角的问题数量可打开列表，用按钮或点击列表项定位问题。诊断功能不添加快捷键。

按 Ctrl+F 或 ⌘F 打开顶部搜索框；编辑器中选中的文字会填入搜索框。搜索框可从左侧拖动调整宽度，按 Esc 关闭。在查找输入框中按回车定位下一个结果，按 Shift+回车定位上一个结果。搜索框还提供大小写、全字、正则、选区内查找，以及单项和全部替换；选区内查找仅在编辑器有选区时可开启。匹配位置会在正文和右侧概览中标出。

底部操作：

- **格式化**：校验 JSON / JSONC 并按 4 个空格缩进，保留注释。
- **去转义**：始终扫描整个编辑区，与光标和选区无关。整份内容是带转义字符串时直接还原；JSON 文档含多个带转义字符串值时分别展示结果，可单独复制、替换，或一次性替换全部。每项还可将 Lua 表数据转成 JSON 并替换原文对应位置。Lua 转换只解析数据字面量，不执行代码。
- **去注释**：移除字符串之外的 `//` 与 `/* … */` 注释，不改动其他内容。
- **压缩**：校验 JSON / JSONC 并移除无用空白，保留注释内容及行注释后的必要换行。需要标准 JSON 时，可先点击“去除注释”再压缩。
- **压缩并转义**：先压缩并保留注释，再输出可还原的 JSON 字符串字面量（含外层引号）；去转义后注释和必要换行仍会保留。

插件通过 `pluginSetting.single: false` 允许 uTools 管理多个原生窗口。临时窗口仍由 uTools 复用；双击标题区域可将其分离为常驻窗口。编辑文件时，原文件不会被自动改写；可用底部“复制全部”取走结果。所有处理均在本地完成。

## 使用方法

1. 在 uTools 中输入 `JSON 编辑器`、`Json` 或 `json-view`；也可以发送 JSON 对象或数组文本，或选择一个 `.json` / `.jsonc` 文件打开。
2. 在编辑区输入或粘贴内容。粘贴有效 JSON / JSONC 时会自动按 4 个空格格式化并保留注释；无效文本仍可编辑和检查。
3. 使用底部按钮转换或复制内容。点击右上角的问题数量可定位问题；按 `Ctrl+F` / `⌘F` 打开查找与替换。

## 环境要求

- Node.js 20.19+ 或 22.12+
- npm
- uTools 与「uTools 开发者工具」插件

## 安装依赖

```bash
npm install
```

## 构建插件

```bash
npm run build
```

构建结果生成到 `plugin/`，包含 `index.html`、`plugin.json`、`preload.js`、`package.json`、`logo.png` 和 `assets/`。在 uTools 开发者工具中选择 `plugin/plugin.json` 接入开发、打包或发布。

## 持续开发

首次构建并在 uTools 中导入 `plugin/plugin.json` 后，运行：

```bash
npm run dev
```

该命令监听源码变化并持续重建 `plugin/`。修改代码后，在 uTools 中重新打开插件查看最新结果。

修改 `src/jsonc.grammar` 后，运行 `npm run generate:parser` 重新生成 `src/jsonc-parser.js`，并将生成的语法文件随源码一同保留。

## 验证

```bash
npm run check
```

该命令依次运行自动化测试并生成生产插件。

验证原生多开时，先在开发者工具中关闭“退出到后台立即结束运行”，结束正在运行的旧插件实例，再重新接入构建后的 `plugin/plugin.json`。若开发接入下仍会关闭已分离窗口，可用开发者工具打包并安装一次，比较已安装版本的窗口行为。

## 目录说明

```text
src/       编辑器界面、诊断、搜索和转换逻辑
public/    uTools 配置、预加载脚本和图标
test/      功能与插件配置测试
plugin/    自动生成的 uTools 插件目录，不提交 Git
```
